Dark-Store Radar

An intelligence stack over the Virar→Andheri quick-commerce corridor — 19 mapped darkstores × Blinkit/Zepto/Instamart, 255k stock + 126k price observations and counting. Semantic core: ~48k product names embedded across five platforms (NVIDIA nemotron-embed + zero-quota local Ollama), entity-resolved so the same milk on five apps is one row, rendered as a live 3D Inventory Atlas with price/store/stock joins. Above it: a Demand Pressure Index — debounced, restart-proof stock-out onsets into chronological per-store demand heatmaps and ETA curves. And the loud apps: a price-glitch monitor firing upstream of the Telegram deal-groups (192 alerts), a five-platform “cheapest X anywhere” bot incl. delivery fees and coupon codes, and an LLM layer writing explainable opportunity reports traceable to raw observations.

Audit Analytics — where the CA meets the code

Local-first journal-entry analytics for Indian statutory & forensic audit teams. It ingests GL/COA extracts with exact control-total reconciliation and SHA-256 evidence copies, ranks explainable risk cues for auditor review, does seeded high-risk sampling, and emits evidence-linked, reviewer-controlled workpapers. Optional semantic transaction search runs on local embeddings only — no client ledger ever leaves the machine, because I know what auditors are actually asked to sign. Built by someone who has read trial balances for the CA Final, not someone who learned "audit" from a dataset.

How I work

  • Orchestrate, don't micromanage. Agents run as fleets against written specs with acceptance gates; humans review artifacts, not transcripts.
  • Receipts over adjectives. Every claim on this page links to code, a live URL, or an architecture doc — including the boring ones.
  • Evidence is the deliverable. A CA-trained instinct: a claim without a workpaper is worthless. So every number in my tools traces back to the record or code that produced it.
  • Question defaults. Deliberately small diffs, deletions over additions, and one runnable check behind anything non-trivial — the code should defend its existence.
